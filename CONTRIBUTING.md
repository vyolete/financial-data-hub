# Contribución

Leer AGENTS.md y docs/engineering/development-workflow.md. Abrir o identificar un issue, acordar alcance y criterios de aceptación, crear rama corta, realizar cambios verificables y abrir PR hacia main. Usar commits descriptivos (Conventional Commits como convención propuesta). No fusionar sin aprobación humana. Indicar pruebas no ejecutadas y limitaciones. No enviar secretos ni datos de terceros sin autorización.

El software se distribuye bajo [Apache License 2.0](LICENSE). Salvo declaración expresa en contrario, toda contribución enviada para su inclusión se ofrece bajo esa licencia (sección 5), sin condiciones adicionales. Quien contribuye debe tener derecho a hacerlo. La exigencia de CLA o DCO está pendiente de decisión. Los datos de terceros conservan sus propias condiciones.
