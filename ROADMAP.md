# Roadmap

Etapas propuestas, sin fechas comprometidas. Seguridad, calidad y confiabilidad son transversales.

| Etapa | Resultado esperado | Estado |
|---|---|---|
| FDH-000 Foundation | Gobierno, contexto común y flujo de trabajo | En revisión |
| SDD Foundation | Framework adoptado y constitución aprobada | En revisión |
| Source Research | Fuentes y condiciones de acceso verificadas | Pendiente |
| Discovery & Catalog | Descubrimiento y catálogo verificables | Pendiente |
| Integration Framework | Contratos y conectores reutilizables; benchmark ETL/ELT | Pendiente |
| Data Platform | Persistencia, calidad, revisiones y linaje | Pendiente |
| Data Services | API y consumo analítico | Pendiente |
| Portal | Interfaz de exploración | Pendiente |
| Operational Maturity | SLO, recuperación y escalabilidad validados | Pendiente |

Cada etapa requiere criterios de aceptación y revisión. Issues y PR registran el estado operativo; este documento no duplica tareas.
