# ADR-0004: Licencia Apache-2.0 para el software

- **Fecha**: 2026-11-25
- **Estado**: Accepted (registro verificable en GitHub pendiente)
- **Autoridad**: aprobada por la dirección del proyecto en sesión de trabajo del 2026-11-25.
  El registro verificable es un comentario personal de la persona mantenedora en el
  [issue #2](https://github.com/vyolete/financial-data-hub/issues/2); aún no consta.

## Contexto

El repositorio es público y no tenía licencia.

## Decisión

Licenciar el software con Apache License 2.0. El texto de [LICENSE](../../LICENSE) se descargó el
2026-11-26 (UTC) de <https://www.apache.org/licenses/LICENSE-2.0.txt>; SHA-256
`cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`.

## Consecuencias

- Las contribuciones se rigen por la sección 5 de la licencia, salvo declaración expresa en
  contrario.
- La licencia no cubre datos ni metadatos de terceros; cada fuente conserva sus condiciones.
- Cada dependencia nueva requiere comprobar que su licencia es compatible.

## Pendiente

Titular de los derechos de autor y necesidad de un archivo `NOTICE`.
