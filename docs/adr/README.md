# Architecture Decision Records

Registrar decisiones significativas con identificador estable, fecha, estado (Proposed, Accepted, Rejected, Superseded), contexto, alternativas, evidencia, decisión, consecuencias y referencias. No modificar retrospectivamente una decisión aceptada: crear una sucesora. Añadir el enlace a su registro de aprobación no modifica la decisión.
