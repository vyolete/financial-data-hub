# Architecture Decision Records

Registrar decisiones significativas con identificador estable, fecha, estado (Proposed, Accepted, Rejected, Superseded), contexto, alternativas, evidencia, decisión, consecuencias y referencias. No modificar retrospectivamente una decisión aceptada: crear una sucesora.

Pendientes: licencia, idioma definitivo, framework SDD, arquitectura tecnológica y almacenamiento. No se consideran decisiones aprobadas por aparecer aquí. La estructura modular y memoria compartida fueron aprobadas para la fundación.
