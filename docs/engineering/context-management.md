# Gestión de contexto compartido

GitHub es la memoria externa versionada, no una sincronización de memorias internas.

| Conocimiento | Fuente canónica |
|---|---|
| Instrucciones comunes | AGENTS.md |
| Visión | docs/product/vision.md |
| Principios formales | .specify/memory/constitution.md |
| Decisiones | docs/adr/ |
| Requisitos | specs/ |
| Contratos aprobados | contracts/ cuando existan |
| Evidencias | research/ |
| Trabajo y bloqueos | Issues y PR |

Cargar solo el contexto necesario: instrucciones, visión, especificación aplicable, ADR y evidencia pertinente. Referenciar documentos en vez de copiarlos. Registrar hechos duraderos mediante PR; marcar hipótesis y decisiones pendientes. No guardar conversaciones completas ni datos privados. Revisar contradicciones y reemplazar decisiones mediante ADR sucesores. Identificar commit o rama al transferir trabajo.
