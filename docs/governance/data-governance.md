# Gobierno de datos

Acceso público no equivale a licencia abierta. Registrar proveedor, identificador, documentación oficial, condiciones de acceso, licencia, redistribución, fecha de verificación y estado de revisión. Si una condición es desconocida, marcarla pendiente y no redistribuir datos.

Preservar procedencia, timestamps de observación e ingesta, revisiones, identificadores y linaje. Definir contratos y reglas de calidad antes de publicar datasets. Minimizar datos personales, limitar recursos y aplicar límites de proveedores. Sanitizar evidencias y notebooks. Almacenar datos masivos fuera de Git; publicar solo muestras pequeñas autorizadas.

La licencia del software y las licencias de fuentes son independientes. Políticas de retención, almacenamiento y recuperación se definirán con la arquitectura.
