# Investigación

Organizar por fuente (sources/colombia/ y sources/international/), benchmarks y experiments, creando directorios únicamente al tener contenido. Cada fuente puede incluir perfil, notebook reproducible, hallazgos y evidencia sanitizada.

Registrar objetivo, documentación oficial, parámetros, fecha UTC, versión de código, solicitudes, errores, métricas, limitaciones y conclusiones. Diferenciar hechos, hipótesis y decisiones. No inventar resultados ni ocultar fallos. Verificar licencias antes de publicar muestras.

El [inventario](sources/inventory.md) registra las fuentes candidatas y su estado.
